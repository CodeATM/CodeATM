**Focus:** AI agents • simulation systems • game systems • distributed computation • real-time rendering

### ⚙️ Engineering Principles

I care about building software that is:

* **Simple** — avoid unnecessary complexity
* **Maintainable** — code should be understandable months later
* **Secure** — security should be part of architecture, not an afterthought
* **Reliable** — failures should be expected and handled
* **Observable** — systems should explain what they're doing
* **Scalable** — architecture should grow with the product
* **Cost-conscious** — especially when designing AI and cloud infrastructure

I generally favor **KISS, DRY, strong boundaries, explicit data flows, and pragmatic architecture** over unnecessary abstraction.
